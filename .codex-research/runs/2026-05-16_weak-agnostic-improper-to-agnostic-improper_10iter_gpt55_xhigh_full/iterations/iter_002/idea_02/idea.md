# Public-Filter Barrier

ID: idea_02

## Summary
Generalize the agreement-filter obstruction. In the RCN model Y=f(X)N, characterize public filters or query distributions built from X, Y, and previous public hypotheses. Prove that any polynomial-mass query with conditional noise below gamma must already encode nontrivial correlation or mutual information about f.

## Why Promising
It turns the solver's local obstruction into a sharper restricted black-box barrier that explorer agents can criticize line by line.

## Risks
Point-mass, empirical-support, and artificial-relabeling queries can break overly broad statements; the theorem must state smoothness and public-information restrictions precisely.

## Suggested Lenses
- oracle lower bound
- information theory
