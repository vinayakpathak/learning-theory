## Summary

The explorer’s main algebraic lemma looks correct and useful: for RCN labels, a label-dependent public filter lowers the noise below `gamma` exactly when its label-asymmetric component already correlates with the hidden target. This is a real strengthening of L007.

The report does not prove anything close to the atlas implication or separation. Its value is as a restricted black-box barrier. The main gaps are definitional: what queries are allowed, how samples and oracle replies contribute information, how to rule out other low-`OPT` witnesses, and how to translate “low noise relative to `f`” into a valid weak-oracle obstruction for a represented class.

## Issue List

- **Missing assumption:** The phrase “public filter” needs a formal sigma-field. If `W_T` is chosen from a transcript containing samples and oracle answers, then `W_T` is not independent of `f`; Lemma 2 only applies to fixed `f`-independent filters. Lemma 3 is the right repair, but then the proof must upper-bound `I(f;T)`.

- **Plausible but incomplete:** Lemma 3 is a valid change-of-measure/information route if the comparison product distribution is set up carefully. But it only gives a lower bound on information needed for success. A barrier also needs an upper bound on information leaked by noisy samples, majority constants, public certificates, and weak-oracle outputs.

- **Fatal gap for atlas separation:** The random all-functions target model is not an efficient represented concept-class construction. This can support an oracle barrier, not the atlas edge itself, unless one supplies a succinct class and an actual efficient fixed-slack weak learner.

- **Missing assumption:** Conditional noise of the hidden `f` is only an upper bound on `OPT_C` when `f in C`. If another `c in C` or public `g` fits the filtered query, the weak oracle may be forced to answer for reasons unrelated to `f`.

- **Missing assumption:** The smoothness/mass parameters must be tied to representation size. The bound `exp(-Omega(tau^2 mu N/L))` is meaningful only when `tau^2 mu N/L` dominates query/sample budgets. If `mu` is tiny or `eta-gamma` is small, the statement can become vacuous.

- **Plausible but incomplete:** The “oracle can stay uninformative” policy is not yet fully specified. On hard-band queries, majority constants are legal, but their signs leak label-bias bits. On low-`OPT` public-witness queries, the oracle can return the public witness only if the model explicitly permits that adversarial policy.

- **Unsupported citation:** The cited SQ papers are relevant background, but they do not by themselves justify the exact public-filter lemmas or the adaptive mutual-information theorem. These claims should be presented as the explorer’s arguments unless a precise known theorem is invoked.

## Counterexamples Or Stress Tests

- **Point mass:** After observing `(x,y)`, query the point mass on `x`. This can have low noise/low `OPT`, but its target mass is negligible. The smoothness or `mu` lower bound must exclude it.

- **Empirical support:** Reweight only sampled points. If the support mass is `M/N`, Lemma 2 gives only an `exp(-Omega(M))` type scale; this is not a global learning barrier unless `M << mu N`.

- **Artificial relabeling:** Query labels generated by a public `g`. This lies outside target-preserving filters and can create `OPT=0` for public reasons.

- **Near-threshold noise:** If `eta = gamma + o(1)`, then `tau_{eta,gamma}` is tiny, so random smooth filters may pass the threshold with non-negligible probability unless `N` is very large.

- **Alternative concepts:** If `C` contains many functions, low `OPT` may come from some `c != f`; the barrier needs a no-other-hidden-witness or random-code condition.

## Literature Or Known-Result Conflicts

No direct conflict with the run’s known state. The result is consistent with L007 and with the existing warning that unrestricted black-box barriers fail due to point masses, empirical queries, and artificial relabeling.

It also does not conflict with da Cunha-style residual-free boosting, because this barrier is restricted to smooth target-preserving public filters and does not address exhaustive clean-label enumeration or arbitrary transcript search.

## What Survives The Critique

- Lemma 1 should be recorded. The formula
  $$
  \eta_W=\frac{\eta(1-r)}{1+(1-2\eta)r}
  $$
  and the threshold
  $$
  r>\frac{\eta-\gamma}{\eta+\gamma-2\eta\gamma}
  $$
  appear correct.

- Lemma 2 is valid for fixed smooth filters independent of the random target, with stated caveats about parameters.

- Lemma 3 is worth pursuing as the adaptive repair, but it needs a full transcript-information accounting.

## Recommended Next Checks

3. Extend Lemma 3 with explicit information upper bounds from `M` noisy samples and `q` oracle answers.

5. Stress-test constants when `eta-gamma` is small and when `mu` is only inverse-polynomial.
