## Summary

The observable residual-forcing idea has a serious RCN obstruction. In random classification noise with noise rate `eta > gamma`, a current predictor can have large excess over the comparator `c=f`, while every smooth query built only from observable residual information `(Y, current prediction)` still leaves `c` with error at least `gamma`.

So the lemma is false in a broad “observable rejection / residual weighting / label randomization” form unless it assumes the current predictor already has substantial correlation with `c`, or it allows queries that are low-OPT but target-mass-useless.

## Concrete Progress

Use the RCN testbed:
$$
Y=f(X)N,\qquad \Pr[N=-1]=\eta,\qquad \gamma<\eta<1/2,
$$
with comparator `c=f`. Let the current binary randomized predictor be `Z`, and write
$$
r=\mathbb E[Zf].
$$

The original excess of `Z` over `f` is
$$
\operatorname{err}(Z,Y)-\eta
= \frac{(1-2\eta)(1-r)}{2}.
$$

Thus for many `r<1`, the predictor still has constant excess.

Agreement filtering gives
$$
\Pr[Y\ne f\mid Y=Z]
=
\frac{\eta(1-r)}{1+r(1-2\eta)}.
$$

This is below `gamma` only if
$$
r>
\frac{\eta-\gamma}{\eta+\gamma-2\eta\gamma}.
$$

Mistake filtering is worse:
$$
\Pr[Y\ne f\mid Y\ne Z]
=
\frac{\eta(1+r)}{1-r(1-2\eta)}
\ge \eta>\gamma
\quad\text{for } r\ge 0.
$$

Concrete parameters: take `gamma=0.1`, `eta=0.25`, `r=0.4`. Then the current excess is `0.15`, but agreement filtering has clean-comparator error `0.125 > gamma`, and mistake filtering has error `0.4375`.

## Claims Or Lemmas

**Restricted obstruction lemma.** In balanced RCN, if the query is generated by a one-sample observable transformation whose acceptance and pseudo-label depend only on `(Y,Z)` and fresh randomness, then no such query can make `f` have error below `gamma` when `r` is below the agreement threshold above.

Reason: the best pseudo-label on each observable cell is just the Bayes decision from the two noisy signs `Y` and `Z`. If neither the agreement nor disagreement cell has posterior error below `gamma`, mixtures of those cells cannot improve it.

**Uncorrelated special case.** If `r=0`, then `Z` carries no information about `f`. For balanced RCN, `N` is independent of `(Y,Z)`, so every observable rejection rule preserves noise rate `eta`; every observable pseudo-label has error at least `eta`. Since `eta>gamma`, residual forcing is impossible, while the predictor excess is still `1/2-eta`.

## Proof Attempts

The loss-gradient or residual-distribution attempt fails on RCN: focusing on examples where the current predictor loses selects `Y\ne Z`, whose noise relative to `f` is at least the original noise.

The agreement-filter attempt helps only after the predictor is already correlated enough with `f`. This is not a first-step forcing lemma; it is a bootstrapping lemma after crossing a correlation threshold.

Label-randomization does not repair this in the observable model. If the pseudo-label is a public function such as `Z`, then `f` is low-error only when `Z` is already close to `f`; otherwise the query is either noisy for `f` or merely low-OPT because of a public witness.

## Gaps And Risks

This is not an atlas separation. It is a restricted counterexample to a class of residual-forcing lemmas.

The obstruction assumes smooth fresh-example queries or one-sample observable transformations. It does not rule out multi-sample clean-witness reconstruction, structural use of `X`, or class-specific algorithms.

Empirical point-mass queries evade the statement syntactically, but they look target-mass-useless: they may create low-OPT queries on observed points without producing global information about `f`.

## Counterexamples Or Obstructions

The main obstruction is: large excess does not imply observable low-noise mass. In RCN, a predictor can be far from optimal, yet the residual region is noisier, not cleaner.

The second obstruction is public-label low OPT. A wrapper can create easy queries by labeling with a public hypothesis, but the weak learner can legally return that public hypothesis, giving no hidden-comparator information.

The third obstruction is empirical memorization. Point-mass or small-support queries can have low apparent noise, but unless the target distribution has heavy atoms, they do not help validation on the original distribution.
