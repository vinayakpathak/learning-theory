## Summary

The broad residual-forcing lemma looks false as a general proof strategy. Excess over a comparator is only a signed average; a fixed-slack weak call needs a query on which the comparator has error below `gamma`. Those are different kinds of information.

A narrower warm-start version may survive: if the current predictor already gives an observable posterior-bias certificate, then filtering/relabeling can create a low-noise query. But this does not explain how to bootstrap from the hard band.

## Concrete Progress

I separated the idea into two required lemmas:

1. **Forcing lemma:** from current excess, construct observable `Q` with `err_Q(c) < gamma`.
2. **Descent lemma:** any weak output on `Q` improves the original predictor or a potential.

The first lemma fails for the most natural residual queries. Let `F` be a randomized predictor, `ell=(1-FY)/2`, `eta=err_D(c)`, and `Delta=err_D(F)-eta`. For the high-loss query `Q ∝ ell D` with labels `Y`,

$$
err_Q(c)=\frac{\mathbb E[1_{Y\ne c}\ell]}{\mathbb E[\ell]}
=\frac{\mathbb E[1_{Y\ne c}\ell]}{\eta+\Delta}.
$$

`Delta>0` gives no useful upper bound on the numerator. The current predictor may be wrong on many noisy points where `c` is also wrong, making the residual query high-noise relative to `c`.

## Claims Or Lemmas

**Lemma 1: Loss-weight residual forcing is not implied by excess.**  
Even if `err_D(F) >= err_D(c)+epsilon`, the query obtained by weighting examples by current loss need not satisfy `err_Q(c)<gamma`.

**Lemma 2: Observable relabeling requires posterior concentration.**  
Fix an observable sigma-field `O` generated by samples, current predictions, confidence buckets, and public randomness. Any rejection/relabeling kernel measurable with respect to `O` can make `c` low-error only by concentrating on cells where the posterior Bayes error of `c` is below `gamma`. Excess alone does not force such a cell.

**Lemma 3: RCN cold-start obstruction.**  
In random classification noise with target `f`, noise `eta>gamma`, and current predictor `Z` with correlation `r=E[Zf]`, conditioning on agreement gives noise

$$
\frac{\eta(1-r)}{1+r(1-2\eta)}.
$$

This is below `gamma` only when

$$
r>\frac{\eta-\gamma}{\eta+\gamma-2\eta\gamma}.
$$

At `r=0`, the current predictor can have constant excess over `f`, but no agreement/disagreement cell based only on `(Y,Z)` has noise below `gamma`.

## Proof Attempts

**High-loss rejection sampling:** fails by the formula above. The bad mass `Y != c` and `F` wrong on `Y` can dominate the residual query.

**Mistake-set filtering:** for deterministic `g`, on `M={g != Y}`,

$$
err_{D|M}(c)=\frac{\Pr[c\ne Y,\ g\ne Y]}{\Pr[g\ne Y]}.
$$

The excess equals `Pr[c=Y,g!=Y] - Pr[c!=Y,g=Y]`; it does not control the numerator.

**Label randomization:** choosing whether to keep or flip `Y` can help only if the observable event predicts whether `Y=c`. Without such posterior information, randomization just trades clean errors for noisy errors.

## Gaps And Risks

The obstruction is not a full lower bound against all reductions. It applies to residual queries whose useful information is mediated by current predictions and observable filters.

It does not rule out algorithms using richer structure of `X`, nonblack-box properties of `A`, clean-witness menus, or class-specific reconstruction.

Even when a low-noise query exists, the descent lemma is separate: a weak hypothesis good on `Q` may only mimic a public label or the current predictor, giving no original-risk improvement.

## Counterexamples Or Obstructions

A simple four-cell decomposition already blocks the naive proof. Let cells be determined by whether `c` is correct and whether current `g` is correct. Excess only says the mass where `c` is correct and `g` is wrong exceeds the mass where `c` is wrong and `g` is correct. It allows large mass where both are wrong, which contaminates the mistake residual.

The RCN example is stronger: with `eta>gamma` and `r=0`, the current predictor has substantial excess over the target, but agreement/disagreement filtering does not create any low-noise query.

## Recommended Next Steps

Formalize a restricted no-go lemma: for any query/relabeling kernel measurable with respect to a transcript sigma-field whose `c`-posterior Bayes error is everywhere at least `gamma`, residual forcing is impossible.

If pursuing the positive route, weaken the target to a warm-start theorem: assume an observable bucket with posterior `Pr[Y=c | bucket] > 1-gamma`, prove the weak call is useful there, then separately search for a mechanism that creates such a bucket.

The counterexample-search lens should try to upgrade the RCN calculation into a clean oracle barrier for residual-forcing boosters.
