## Summary

The explorer’s core finite-cell LP claim looks correct in its intended one-step model. If the only allowed query operations are nonnegative filtering and sign relabeling measurable with respect to a fixed public partition `G`, then the best comparator-error query is exactly

\[
\min_{i:p_i>0}\frac{\min\{u_i,v_i\}}{p_i}.
\]

The main critique is scope. This is a useful obstruction to residual-forcing from excess alone, not an atlas-level lower bound and not a no-go theorem for adaptive algorithms, arbitrary `X`-dependent filters, or low-`OPT_C` queries witnessed by other concepts.

## Issue List

1. **Missing assumption: public sigma-field must be fixed and explicit.**

   The phrase “arbitrary public filters” is too broad unless “public” means `G`-measurable for a specified finite partition. If `G` includes too much `X`-side information, especially enough to isolate where `c(X)=Y`, the LP optimum can drop to zero. The obstruction needs the hypothesis

   \[
   \Pr[c(X)\ne Y\mid G=i]\in[\gamma,1-\gamma]
   \]

   for every allowed public cell.

   Classification: **missing assumption**.

2. **Fatal gap if promoted beyond one-step residual forcing.**

   The result rules out one-step residual queries built from a fixed public partition. It does not rule out multi-step methods that create posterior variation through new samples, repeated-coordinate denoising, weak-oracle outputs, validation, or class-structured inference.

   Classification: **fatal gap for any atlas-level negative claim**, but not fatal for the stated finite LP lemma.

3. **Concrete witness needs `C` and near-optimality specified.**

   The explorer sets `err(c)=eta` and `err(g)=m>eta`, but to connect to the main problem one should instantiate a class, e.g. `C={c}` or a class where `c` is near-optimal and constants/other concepts do not beat it. Otherwise the example only says “some comparator has lower error than `g`,” not that it represents `OPT_C`.

   Classification: **plausible but incomplete**.

4. **Low comparator error is not equivalent to low `OPT_C`.**

   The LP tracks the error of one comparator `c` under relabeling. A weak call is triggered by `OPT_C(Q)<gamma`, possibly witnessed by a public constant, artificial relabeling, empirical memorizer, or another concept. The explorer acknowledges this, but it must remain explicit in any ledger update.

   Classification: **missing assumption / known obstruction**.

5. **The “best possible” sign choice may be omniscient.**

   The proof minimizes over signs choosing `min{u_i,v_i}` per cell. A real algorithm may not know which sign is better. For a lower bound this is harmless: if even the omniscient cellwise choice cannot get below `gamma`, no public method can. But the statement should not be read constructively.

   Classification: **worth clarifying**.

6. **Query mass and sampleability are omitted.**

   The exact optimum allows concentration on any positive-mass cell. For the negative constant-posterior witness this is harmless because no cell is good. For positive variants or LP extensions, minimum mass/smoothness and efficient rejection sampling become necessary.

   Classification: **plausible but incomplete**.

## Counterexamples Or Stress Tests

A clean stress test for the narrow claim is:

\[
\gamma=0.10,\qquad \eta=0.15,\qquad m=0.20.
\]

Let the public partition be generated by `(Y,g(X))`, and arrange

\[
\Pr[c(X)\ne Y\mid Y,g(X)] = \eta
\]

in every sign-specific cell, while

\[
\Pr[g(X)\ne Y]=m.
\]

Then

\[
\operatorname{err}(c,Y)=0.15,\qquad \operatorname{err}(g,Y)=0.20,
\]

so `g` has positive excess over `c`, but every public filter/relabeling measurable with respect to `(Y,g)` has comparator error at least `0.15>gamma`.

Stress test against overclaiming: if the public partition is refined to expose the clean/noisy indicator `1[c(X)=Y]`, then cells with comparator error zero exist. Thus the obstruction is really a posterior-invariant condition on the allowed public information.

## Literature Or Known-Result Conflicts

No direct conflict with the run’s ledger. The result is consistent with:

- L010 / C012: excess alone does not force low-noise mistake or high-loss residuals.
- L019: public filtering/relabeling cannot lower comparator noise if every public cell has posterior comparator error `eta>gamma`.
- O011: sign-specific cells can matter; the explorer includes them rather than relying on aggregate agreement/mistake filters.

It should not be cited as an SQ/oracle lower bound or as a weak-to-strong separation.

## What Survives The Critique

The finite-cell algebra survives.

The useful lemma to record is:

> For a fixed public finite partition `G`, among all `G`-measurable nonnegative filters and `G`-measurable sign relabelings of `Y`, the minimum possible error of comparator `c` is  
> \[
> \min_i \min\{ \Pr[c\ne Y\mid G=i],\Pr[c=Y\mid G=i]\}.
> \]
> Therefore positive excess `err(g)>err(c)` does not by itself imply any weak-callable public residual with comparator error below `gamma`.

This is worth pursuing as a crisp obstruction to residual-forcing proof attempts.
