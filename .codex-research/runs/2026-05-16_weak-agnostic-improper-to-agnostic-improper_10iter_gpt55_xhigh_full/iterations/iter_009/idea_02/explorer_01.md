## Summary

The realized-call audit gives a useful but limited extraction. In the da Cunha-Hogsgaard-Paudice 2026 proof, global `Range(A)` control is **not** needed merely to justify the adaptive weak calls: the proof only needs the weak guarantee on the realized AdaBoost distributions over the hidden clean empirical sample.

However, this does **not** remove the main bottleneck. Global or replacement capacity is still needed for the hidden-clean empirical-to-population transfer, and an efficient selector is still needed for the final `sign(B^(T))` class.

## Concrete Progress

The DCHP proof separates into three logically distinct steps:

1. **Realized adaptive clean-call simulation:** succeeds with only per-round conditioning and a union/product bound over the realized AdaBoost trajectory.
2. **Hidden-clean population transfer:** still uses uniform convergence over `sign(H^(T))`; finite realized bags do not replace this because the bag depends on the same hidden clean sample it later fits.
3. **Final noisy validation:** can be localized to a validation-independent finite list or finite vote class over `B`, but computation of the best sparse majority remains a separate selector problem.

A useful extraction is:

**Realized Clean Simulation Lemma.**  
Let `C = S_{f*}` be the hidden clean empirical sample. Suppose a weak learner satisfies the DCHP agnostic weak condition with `theta = (gamma0 - epsilon0)/2`. For each realized AdaBoost round distribution `D_r in Delta(C)`, conditional on the previous successful rounds, there exists an ordered clean tuple `I_r in C^m0` such that a fresh seed makes `W(C|I_r, seed)` have `D_r`-loss at most `1/2 - theta` with probability at least `1 - delta0`. Enumerating all tuples in `S1^m0` and using  
`M >= log(5R/delta)/log(1/delta0)` seeds per tuple gives success for all `R` realized rounds with probability at least `1 - delta/5`.

This is exactly a realized-call argument; it does not union bound over all possible distributions on `C`.

## Claims Or Lemmas

**Claim 1: Weak-call validity can be realized-call local.**  
Supported. The proof only needs the weak learner for the actual adaptive distributions generated by the simulated AdaBoost run.

**Claim 2: Final validation can be finite-list local.**  
Supported. If `B` is fixed before held-out `S2`, validation over `V_{B,T}=sign(B^(T))` can use a finite bound with  
`log |V_{B,T}| <= T log |B|`, or over any explicit polynomial final list. This avoids global `Range(A)` only for the final validation step.

**Claim 3: Hidden-clean population transfer still needs capacity, compression, stability, or independence.**  
Supported obstruction. The selected vote is chosen after seeing/generated-from the hidden clean sample, so a finite-bag argument is circular. This is where `VC(sign(H^(T)))` or a replacement theorem is genuinely doing work.

**Claim 4: Dual VC is avoidable only by paying elsewhere.**  
One can skip pruning and take `T=R=O(log n/theta^2)`, avoiding `d*` statistically, but final search becomes `|B|^T`, generally quasi-polynomial or worse. Thus dual VC is not needed for semantic existence, but it is part of the known runtime improvement.

## Proof Attempts

**Attempt A: Replace weak-call range assumptions by realized calls.**  
This works. For a realized `D_r`, weak learning over clean samples gives average success over `(tuple, seed)`, hence some clean tuple has high seed success. Enumeration over all tuples finds it. Repeating seeds amplifies. Only `R` realized rounds are charged.

**Attempt B: Replace final global validation by finite validation over generated classifiers.**  
This works if the final candidate set is fixed before the held-out validation sample. It does not solve how to search the set.

**Attempt C: Replace clean empirical-to-population transfer by finite generated bag size.**  
This fails. Since `B` is generated from `S_f*`, a classifier in `sign(B^(T))` can fit `S_f*` for sample-dependent reasons while having poor clean population error. This is the same obstruction as the singleton memorizing-bag example in the notes.

## Gaps And Risks

The atlas source still does not provide:

- bounded `m0`; enumeration costs `n^m0`;
- controlled semantic `H=Range(A)`;
- controlled `VC(H)` or `VC*(H)`;
- an efficient selector for exact DCHP sparse majorities;
- stability/compression replacing clean-sample uniform convergence.

Endpoint issue: DCHP theorem statements use `gamma0, epsilon0 in (0,1)`. If `gamma0=1` is not allowed, the L009 interior repair remains necessary.

## Counterexamples Or Obstructions

- Finite generated bags can overfit hidden clean samples.
- Rare-slice weak learners show semantic weak correctness does not control global range or dual VC.
- Exact sparse-majority ERM over arbitrary bags is Set-Cover hard, so a generic `ApproxSparseMajorityERM(B,T)` primitive is unavailable.
