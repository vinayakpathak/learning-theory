## Summary

Idea 02 should be pursued mainly as a negative/minimax result. A fully general residual low-`OPT` lemma cannot follow from positive excess alone. The right invariant is the public posterior of the hidden comparator relative to the sigma-field generated by the current predictor, transcript, labels used for filtering, and public randomness.

If every public cell has comparator posterior noise in the band
\[
\min\{\eta_G,1-\eta_G\}\ge \gamma,
\]
then no public filtering or relabeling scheme can make the hidden comparator a below-`gamma` witness. Positive excess of the current predictor over that comparator is compatible with this invariant.

So the promising proof strategy is not “derive low `OPT` from excess,” but:

1. prove a public-posterior envelope theorem for all residual schemes in this grammar;
2. use it to block residual-forcing arguments;
3. identify what extra condition would be needed, namely a transcript-created lower posterior tail or a target-useful low-`OPT` routing lemma.

## Concrete Progress

A general public residual scheme can be modeled as follows. Let `G` be the sigma-field containing everything public before the weak call: current soft predictor `F`, previous transcript, the observable example coordinates, observed labels, and any public/randomized filtering decisions. A query chooses a nonnegative weight `W`, with `W` `G`-measurable, and a query label `Z in {+-1}`, also `G`-measurable after adding public randomness.

For a fixed comparator `c`, define
\[
m_Z(G)=\Pr[c(X)\ne Z\mid G].
\]
Then the comparator error on the query is exactly
\[
\operatorname{err}_{Q_{W,Z}}(c)
=
\frac{\mathbb E[W\,m_Z(G)]}{\mathbb E[W]}.
\]

Thus public filtering can only average conditional posterior errors already present in the public partition. It cannot create hidden-comparator low noise from a flat public posterior.

If relabelings are restricted to `Z=S(G)Y`, then
\[
m_Z(G)=
\begin{cases}
\eta_G & S=+1,\\
1-\eta_G & S=-1,
\end{cases}
\qquad
\eta_G=\Pr[c(X)\ne Y\mid G].
\]
So the best possible public relabeling/filtering error for `c` is governed by the lower tail of
\[
m(G)=\min\{\eta_G,1-\eta_G\}.
\]

With a mass constraint such as `0 <= W <= 1` and `E W >= alpha`, the optimum is the lower-tail/CVaR average of `m(G)`, not merely its essential infimum. Therefore any efficiently sampleable residual query needs non-negligible public mass where `m(G)<gamma`.

## Claims Or Lemmas

**Lemma 1: Public residual envelope.**  
For any public randomized filtering/relabeling scheme whose query distribution is generated by `G`-measurable weights and labels,
\[
\operatorname{err}_Q(c)
=
\frac{\mathbb E[W\Pr[c(X)\ne Z\mid G]]}{\mathbb E[W]}.
\]
Consequently, if `Pr[c(X) != Z | G] >= gamma` almost surely for every allowed public label `Z`, then no allowed query makes `c` a below-`gamma` witness.

**Lemma 2: Sign-relabeling specialization.**  
If allowed labels are `Y` or `-Y` cellwise, then the necessary and sufficient local quantity is
\[
\min\{\Pr[c\ne Y\mid G],\Pr[c=Y\mid G]\}.
\]
A low-noise residual exists only if this quantity has a below-`gamma` public lower tail.

**Lemma 3: Excess does not imply a lower posterior tail.**  
For any `gamma < eta < 1/2` and any small `Delta < 1/2-eta`, there are distributions and public predictors `g` such that
\[
\operatorname{err}(c,Y)=\eta,\qquad
\operatorname{err}(g,Y)=\eta+\Delta,
\]
but
\[
\Pr[c(X)\ne Y\mid Y,g(X)]=\eta
\]
on every public cell. Hence `g` has positive excess over `c`, while no public filter/relabeling over `(Y,g(X))` makes `c` have error below `gamma`.

## Proof Attempts

The positive route would need a statement like:

> If `F` has excess more than `epsilon`, then some public residual query has `OPT_C < gamma` and every legal weak answer gives descent.

The envelope lemma shows where this can fail. Excess gives an average comparison between `F` and `c`, but the useful residual set is essentially the hidden disagreement set `{F disagrees with c}` or a related hidden clean/noisy separator. That set is not public unless the transcript already contains information about `c`.

The flat-posterior construction makes this explicit. Let public cells be indexed by `(Y,g(X))`. Inside every cell, arrange the deterministic comparator `c` to disagree with `Y` on an `eta` fraction of the cell. Choose the masses of cells so that `g` has error `eta+Delta`. Then `g` is worse than `c`, but every public cell has the same comparator noise `eta > gamma`. Filtering, conditioning, and sign relabeling only take averages of `eta` and `1-eta`; neither is below `gamma`.

This does not give an atlas separation, because the class may contain other concepts witnessing low `OPT`, and public/artificial labels can make low-`OPT` queries for irrelevant reasons. But it does refute the core proof step “excess alone forces a useful residual weak call.”

## Gaps And Risks

The main gap is translating the public-posterior obstruction from “`c` is not low-noise” to “`OPT_C` is not low.” A query can have `OPT_C < gamma` because of a public constant, public anchor, empirical spike, artificial relabeling, or another concept in `C`. Such queries may trigger the weak learner but need not help with the hidden comparator.

A second gap is descent. Even if `OPT_C(Q)<gamma`, a fixed-slack improper weak oracle may return any legal hypothesis. To use the query, one needs either target-witness uniqueness or a guarantee that every legal answer correlates with the original descent direction. Low `OPT` alone is too weak.

A third risk is sample access. Very small posterior-tail cells may exist but be unsampleable in polynomial time. A useful positive lemma needs explicit mass, smoothness, or rejection-sampling cost bounds.

## Counterexamples Or Obstructions

The strongest obstruction is the flat public posterior example: positive excess with no public low-noise cell.

A separate obstruction is public-witness low `OPT`: if the wrapper relabels by a public anchor or constant, the query may be perfectly learnable for public reasons. An adversarial legal weak learner can return the public witness, yielding no target progress.

The hidden disagreement identity remains the conceptual blocker:
\[
\operatorname{err}(g,Y)-\operatorname{err}(c,Y)
=
\mathbb E[1_{g\ne c}c(X)Y].
\]
The biased set exists, but it depends on `c`, not just on the public transcript.
