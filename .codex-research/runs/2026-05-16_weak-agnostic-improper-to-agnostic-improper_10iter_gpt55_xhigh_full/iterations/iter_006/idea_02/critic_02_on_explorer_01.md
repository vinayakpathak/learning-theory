## Summary

The explorer’s main negative message is worth keeping: positive excess over a comparator does not by itself force a useful one-step public residual query. The public-posterior envelope identity is correct in the restricted model.

The report should not be promoted as a “most general residual low-`OPT`” obstruction yet. The main fatal gap is that the sigma-field model conflates public/computable information with ordinary measurability. If `G` literally contains the observed coordinate `X` and `c` is a fixed deterministic concept, then `c(X)` is `G`-measurable, so the posterior `Pr[c(X) != Y | G]` is usually `0` or `1`, not flat. To make the argument valid for full PAC queries, one needs either a coarse public feature sigma-field, or a random-hidden-target/information model.

## Issue List

- **Fatal gap: public sigma-field vs raw `X`.**  
  The explorer says `G` can contain observable coordinates. In the usual fixed-distribution view, if `G` contains `X`, then deterministic `c(X)` is measurable. The flat posterior obstruction only works for a coarser `G`, such as cells generated by `(Y,g(X))`, or in a Bayesian/random-target model where `c` is hidden randomness not revealed by `X`.

- **Missing assumption: allowed query grammar.**  
  The sign-relabeling result is clean for labels `Z=S(G)Y`. For arbitrary public labels, the relevant local quantity is `Pr[c(X) != Z | G]`, or pointwise `min_z Pr[c(X) != z | G]`, not just `min{eta_G,1-eta_G}`. Public anchors/constants must be modeled separately.

- **Plausible but incomplete: low comparator noise vs low `OPT_C`.**  
  The envelope only shows that a fixed comparator `c` is not a below-`gamma` witness. It does not show `OPT_C >= gamma`. Other concepts, constants, empirical memorization, or public anchors can make `OPT_C` small for irrelevant reasons.

- **Fatal for positive use: no descent guarantee.**  
  Even if a residual query has `OPT_C < gamma`, an improper fixed-slack oracle may return any legal binary hypothesis. The report correctly notes this, but it means the residual route still needs a separate “every legal answer gives original-risk descent” lemma.

- **Plausible but incomplete: flat-posterior counterexample generality.**  
  The four-cell construction refutes residual forcing relative to `G=(Y,g(X))`. To cover soft predictors and transcript-generated features, it should be restated for an arbitrary finite public partition. To cover full `X`-dependent algorithms, it needs a random-target/information-budget upgrade.

- **Worth pursuing: lower-tail/CVaR formulation.**  
  The mass-constrained filter statement is the right convex dual object, but the report should state exact constraints: `0 <= W <= L`, `E W >= alpha` or `= alpha`, and whether fractional filtering is sampleable.

- **Unsupported citation: none material.**  
  The explorer uses local run notes only and does not rely on a new external theorem.

## Counterexamples Or Stress Tests

- **Raw-coordinate stress test.**  
  Let `G=sigma(X,Y)`. Since `c` is deterministic, `Pr[c(X) != Y | G]` is the clean/noisy indicator itself. The claimed flat-posterior obstruction disappears. This is the strongest test the sigma-field formalism must repair.

- **Public anchor stress test.**  
  If query labels are a public anchor `a(X)` and `C` contains `a`, then `OPT_C=0` on that query regardless of whether the hidden comparator has low posterior noise. A weak learner can return `a`, giving no target progress.

- **Coarse flat-posterior example survives.**  
  For `G=(Y,g(X))`, arrange each cell so `Pr[c != Y | G]=eta` with `gamma < eta < 1/2`, and choose cell masses with `err(g,Y)>eta=err(c,Y)`. Then no `G`-measurable sign filter/relabeling makes `c` below `gamma`.

- **Hidden disagreement stress test.**  
  The useful set `{g != c}` can carry the excess signal, via  
  `err(g,Y)-err(c,Y)=E[1_{g != c} c(X)Y]`,  
  but this set is not public unless the transcript already contains information about `c`.

## Literature Or Known-Result Conflicts

No direct conflict with known boosting results. Classical realizable boosting avoids the obstruction because labels are clean relative to `c`. Residual-free agnostic boosters such as the da Cunha route do not rely on this one-step public residual lemma; their bottleneck is hidden-clean tuple generation/capacity/runtime. SQ-style lower bounds are only analogous unless the query grammar and oracle-output information leakage are formalized.

## What Survives The Critique

The envelope identity survives:

\[
err_Q(c)=\frac{E[W\,Pr[c(X)\ne Z\mid G]]}{E[W]}.
\]

The sign-relabeling specialization also survives for a fixed public sigma-field not revealing `c(X)`:

\[
err_{W,S}(c)=
\frac{E[W(\eta_G1_{S=1}+(1-\eta_G)1_{S=-1})]}{E[W]}.
\]

The flat-posterior construction is a valid obstruction to proofs that use only positive excess plus a coarse public partition. It should be recorded as a one-step residual-forcing failure, not as an atlas lower bound.
