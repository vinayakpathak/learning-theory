# Efficient Realizable Proper PAC Learning $\Rightarrow$ Efficient Agnostic Proper PAC Learning

## Verdict

`false`, under the assumption $\mathrm{RP} \ne \mathrm{NP}$.

Conjunctions are efficiently properly learnable in the realizable PAC model by the classical elimination algorithm. Kearns, Schapire, and Sellie show that properly agnostically learning conjunctions would imply a randomized polynomial-time algorithm for minimum set cover.

## Proof Sketch

**Goal.** Refute the universal implication, assuming $\mathrm{RP}\ne\mathrm{NP}$. It is enough to exhibit a class that is efficiently realizably properly learnable but is not efficiently agnostically properly learnable under that assumption.

**Construction.** Let $\mathcal T_n$ be the class of conjunctions of literals over $x_1,\dots,x_n$.

**Why the source property holds.** In the realizable proper PAC problem, labels are generated by some target conjunction $c\in\mathcal T_n$. The standard elimination learner starts with all literals

$$
x_1,\neg x_1,\dots,x_n,\neg x_n
$$

and deletes every literal falsified by a positive example. Every literal in the target conjunction survives, so the final conjunction is consistent with every realizable sample. Since $\mathcal T_n$ has finite VC dimension and the elimination procedure runs in time polynomial in the sample size and $n$, conjunctions are efficiently properly learnable in the realizable model.

**Why the target property fails.** Kearns, Schapire, and Sellie reduce minimum set cover to proper agnostic learning of conjunctions. At a high level, a set cover instance with sets $S_1,\dots,S_n$ is encoded by variables $x_1,\dots,x_n$. A monotone conjunction $\bigwedge_{j\in B}x_j$ selects the subfamily $\{S_j:j\in B\}$. The constructed distribution has negative examples that force $B$ to cover every object, positive examples that charge one unit of error for each selected set, and a heavy all-ones positive example that makes negative literals too costly. Therefore any conjunction whose error is within a small inverse-polynomial additive tolerance of the optimum determines an exact minimum set cover.

**Conclusion.** If conjunctions had an efficient proper agnostic PAC learner, running it on the constructed distributions with the specified inverse-polynomial accuracy would solve minimum set cover in randomized polynomial time. That would imply $\mathrm{RP}=\mathrm{NP}$. Hence, under $\mathrm{RP}\ne\mathrm{NP}$, efficient realizable proper PAC learning does not imply efficient agnostic proper PAC learning.
