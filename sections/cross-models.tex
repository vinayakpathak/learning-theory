\chapter{Cross-Model Connections}

This chapter will eventually contain the main comparison tables of the atlas.

Examples of questions to encode here:

\begin{itemize}
\item when does online learnability imply batch learnability
\item which active-learning guarantees refine PAC guarantees and which are incomparable
\item how statistical-query learnability relates to noise tolerance
\item which statistical notions imply prediction guarantees and which do not
\end{itemize}

The intended end state is a collection of compact implication tables with short proofs or citation pointers, plus a ledger of missing arrows that deserve dedicated investigation.
